* Classes
-> classes in js are template for creating objects.
-> they encapsulate data and behavior into a single structure

* Getters and setters
->Getters and setters are special methods that allows controlled access to properties getters retrieve values setters modify them
-> they are accessed like properties and not methods

* StaticMethods
-> static methods bwlong to the class itself, not to instance
-> they are called on the class and not on objects


*  private fields
-> Private fields are written with # prefix and can only be accessed inside the class
-> they provide true encapsulation
